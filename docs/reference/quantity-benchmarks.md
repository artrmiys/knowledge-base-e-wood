# Quantity benchmarks: исторические ориентиры

Ниже сохранены числа из прежней внутренней выборки, описанной как **180+
takeoff'ов**. Это исторические примеры для разбора, а не актуальный счётчик базы
или нормы для нового проекта.

!!! note "Статус на 6 сентября 2026"
    Выборка и её дата, scope каждого проекта и исходные расчёты в этом обновлении
    не перепроверялись. Значения таблиц сохранены. Подтверждать правильность takeoff
    по попаданию в диапазон нельзя: сначала нужны scope, единицы и размеры проекта.

!!! tip "Как пользоваться"
    Медиана и диапазон `[q1–q3]` помогают сформулировать вопрос для проверки.
    Например, сами по себе 66 anchor bolts при 350 ft termite shield не доказывают
    правильность: количество нужно сверить с деталями и spacing текущего проекта.

## Внутренние факторы { .kb-section-title .kb-st--green }

| Фактор | Значение | Область применения |
| --- | --- | --- |
| Studs 16" o.c. | **×1.1** | Внутреннее правило «1 стойка/фут + 10% waste», не геометрические 0.75; см. канон формул. |
| Studs 24" o.c. | **×0.625** | Внутреннее правило «0.5 + 25% waste»; см. канон формул. |
| Waste general | **×1.10** | Прежнее сравнение с 10–15% не подтверждает универсальную норму; проверяй, не включён ли waste ранее. |
| Rim EWP | **×1.05** | Правило для EWP-jobs; не переносить автоматически на другой scope. |
| Bracing | 1 / 8 ft | Внутренний ориентир; сверять с проектом. |

## Метод, предложенный в прежнем исследовании { .kb-section-title .kb-st--blue }

В исследовании предлагалось сравнивать пары `(секция, строка)` по сопоставимым
проектам и использовать **Tukey fences**: значение вне
`[q1 − 1.5·IQR, q3 + 1.5·IQR]` или вне corpus min–max отмечать для проверки.
Это сохранённое описание метода, а не подтверждение, что проверка сейчас запущена
или встроена в программу. Применимость диапазонов и число ложных тревог требуют
отдельной проверки. Статус — в [ИИ-ассистенте](ai-assist-system.md).
