# OurPlanCore — что нового

Проверено 6 сентября 2026. Новая версия **2.2.7 Preview** устанавливается
отдельно. Возможности ниже относятся к соответствующему выпуску, а не
автоматически к любому старому EXE.

## 6 сентября — 2.2.7 Preview

| Изменение | Польза в работе |
| --- | --- |
| Отдельное окно Keyboard Shortcuts | Назначение и смена клавиш для команд, включая зеркала; поиск, конфликты, Reset, пресеты, общий и проектный набор |
| Стабильная фильтрация растра после zoom | Лист перестал переключаться на резко квадратное изображение после остановки увеличения |
| Исправление кеша по длинным путям | Подготовленный растр читается и из глубоко вложенной рабочей папки |
| Доработка очереди перерисовки и хранения растров | Запрос обновления кадра не теряется; уменьшено лишнее копирование изображения |
| Быстрее сохранение и закрытие больших проектов | Убраны повторные проверки одних и тех же путей при упаковке метаданных |
| Общая вставка между листами | Same takeoffs / New takeoffs / Cancel в основном и отдельном окне; исправлена отмена созданных позиций |
| Защита данных и recovery | Повреждённые или недоступные project data не подменяются пустыми значениями; доступны повторное чтение и восстановление из копии |
| Журнал операций Pages | Восстановление прерванных операций и отмена соответствующей сортировки/операции |
| Отдельный профиль Preview | Новая версия использует свои настройки и рабочие копии |

Клавиши, которые уже работали, сохраняют исходные назначения. Сочетания для
зеркал можно выбрать самому: [инструкция](ourplancore-shortcuts.md).

Проверки выполнялись на копиях заполненных проектов до **214 листов и 3589
замеров**, с открытием листов, zoom/pan, сохранением, повторным открытием и
экспортом. Общий набор финальной сборки: **807 C# и 29 Python проверок**.
Это результат конкретной сборки и сценариев, а не гарантия любого входного файла.

## 5 сентября — инструменты и живое PDF Preview

- Beam и Openings получили полноценное завершение в отдельном окне листа.
- У Beam регулируется отступ размера; линия замера остаётся на измеренных точках.
- `PDF Output → Preview` показывает текущий лист и обновляется при изменении
  параметров вывода; есть zoom, панорамирование и Fit.
- `Move joist note` позволяет двигать таблицу Joist. Опция изначально выключена;
  положение сохраняется, участвует в Undo и экспорте PDF.
- Повторное рисование Beam и Line помогает создавать отдельные сегменты подряд.
- Выровнены элементы лент PDF Output и Viewport.

## Ранее: переносимый проект и рабочие инструменты

- Новые проекты сохраняются как `.ourplan`; единый `Open project...` открывает
  также старые папочные проекты. `Save As` сохраняет формат текущего проекта.
- Pitch, Value export, дополнительные Joists, настройки отображения,
  модули и специализированные менеджеры описаны в
  [справочнике инструментов](ourplanecore.md).

## Что остаётся ограничением

Перенос основного приложения на .NET 10 не выполнен: отдельный эксперимент
не прошёл все Excel-проверки. Общие настройки/пресеты ещё не все имеют защиту
нового project-data reader. На больших проектах остаются направления работы
с деревьями и памятью; улучшение Save не означает ускорение каждой операции.
