# OurPlanCore — решение проблем

Проверено по **2.2.7 Preview, 6 сентября 2026**. Начни с симптома. Названия
команд относятся к этому выпуску; старый EXE может иметь другой набор функций.

## Кнопка или клавиша не работает

| Симптом | Что проверить |
| --- | --- |
| Нет нужной панели | `8 Settings → Modules`: включён ли соответствующий модуль; проверь override открытого проекта. |
| Нет новой функции | Запущена ли нужная версия через её ярлык. Старый выпуск не обновляется от установки отдельного Preview. |
| Клавиша печатает букву | Фокус находится в текстовом поле. Заверши ввод и верни фокус на нужное окно/viewport. |
| Назначение не вызывается | Открой [Keyboard Shortcuts](ourplancore-shortcuts.md), найди команду, проверь сочетание, контекст и предупреждения о конфликте. |
| Зеркало недоступно | Выдели подходящие замеры. Отличай зеркало выбранных объектов от переворота самого листа. |
| Редактирование заблокировано | Проверь read-only и сообщение о доступе к проекту. Отключённый модуль и read-only не обходятся новой горячей клавишей. |

## Замер не виден или число отличается

1. Проверь текущий проект и лист в `Pages`.
2. Проверь видимость takeoff на листе и сам выбранный takeoff item.
3. Проверь тип замера, единицы и масштаб конкретного измерения.
4. При копировании между листами проверь целевой лист и режим Same/New.
5. При переносе старой папки используй `Repair Links`, если проблема относится
   к старым связям. Не создавай дубликаты замеров до проверки.

Новый DPI или zoom меняет изображение, а не физический размер замера.
Для проверки масштаба используй известный размер исходного чертежа.

## Сохранение или открытие не завершилось

| Сообщение / ситуация | Действие |
| --- | --- |
| Сохранено в local recovery | Перед передачей нажми `Save` и дождись обновления `.ourplan`. |
| Файл изменён вне этого окна | Сохрани свою работу через предложенный `Save As`; сначала разберись, какая внешняя копия нужна. |
| Недостаточно места | Упакованный размер меньше места, нужного для распаковки и работы. Освободи место вне активных проектов/recovery. |
| Защищённый JSON метаданных в открытом проекте | `Open / Import → Project Data Recovery...`: выбери запись из списка, затем `Retry reading` либо `Restore from copy...`. |
| Сам `.ourplan` не читается | Следуй предложению приложения открыть сохранённую local recovery, если она найдена. Диалог Project Data Recovery не ремонтирует ZIP или PDF. |
| Ошибка сохраняется | Сохрани текст сообщения, версию приложения, шаги и рабочую копию. Не удаляй её ради повторного запуска. |

Пошаговые действия и границы восстановления:
[проекты, сохранение и бекап](job-creation-storage.md#backup).

## Тяжёлый лист медленно открывается

- Проверь, подготовлен ли растр для этого листа, а не только включён Raster First.
- Для пакетной подготовки в `Sheet Manager` выбери листы, формат PNG и DPI,
  нажми `Prepare`, дождись завершения, затем включи `Raster First On`.
- Проверь масштаб просмотра и сравни заполненные листы одного проекта.
- Если замедление связано с переключением листов, раскрытием дерева или Save,
  запиши именно эту операцию: это разные причины и разные измерения времени.

В 2.2.7 исправлены переключение резкости после остановки zoom и ошибки чтения
кеша по длинным путям. Это не обещание мгновенного открытия любого PDF или
полного отсутствия задержек на больших проектах.

## PDF выглядит иначе

`Viewport` настраивает экран, `PDF Output` — вывод. Проверь настройки нужной
ленты и видимость takeoffs. `PDF Output → Preview` показывает текущий лист;
это не предварительный просмотр сразу всего выбранного набора.

Открой готовый PDF отдельно: проверь набор листов, читаемость подписей,
геометрию и легенду. Скрытые takeoffs могут не включаться в вывод согласно
выбранным параметрам.

## Excel получил неожиданные строки или макрос остановился

Проверь выбранную книгу, лист, ячейку и область takeoffs. У обычной записи,
`Value` и macro actions разные назначения. Macro actions зависят от структуры
и VBA конкретного шаблона; `ALL` требует однозначного корня здания.

При ошибке не запускай тот же пакет повторно вслепую: часть строк могла уже
попасть в книгу. Сверь результат, исходную копию и сообщение об ошибке.
Сохранение Excel выполняется отдельно. [Excel macro hotkeys](excel-hotkeys.md)
относятся к VBA книги, а не к редактору клавиш OurPlanCore.
