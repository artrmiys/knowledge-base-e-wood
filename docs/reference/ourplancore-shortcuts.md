# Горячие клавиши OurPlanCore

Проверено по **2.2.7-preview, 06.09.2026**. Здесь — назначение клавиш,
контексты команд и исходные сочетания. В старой версии редактора может не быть.

## Назначить или поменять клавишу

1. **`Settings → Keyboard Shortcuts → Open Keyboard Shortcuts...`**.
2. Найди команду по названию/категории и выдели строку. Например, поиск `Mirror`
   покажет `Mirror selected objects horizontally` и `Mirror selected objects vertically`.
3. Нажми поле **`New shortcut`**, введи сочетание, затем **`Assign`**.
   Для последовательности до трёх нажатий включи `Sequence`; пример — `B, K`.
4. Если сочетание занято в совместимом контексте, редактор покажет конфликт и
   запросит перенос. Проверь, у какой команды снимается прежнее назначение.
5. Нажми **`Save global default`** для всех проектов или **`Save for this job`**
   для текущего доступного для записи проекта. Job override имеет приоритет;
   **`Use global for this job`** снимает его.

**До Save старые клавиши продолжают работать.** `Remove keys` убирает назначения
выбранной команды; `Reset command` и `Reset all to original` возвращают исходные
назначения в черновике. Затем также нужен Save. `Import preset...` загружает
черновик из JSON, `Export preset...` сохраняет его отдельным файлом.
`Clear capture` очищает только поле ввода нового сочетания.

Каталог включает инструменты, команды деревьев и меню, элементы рабочих вкладок
и открываемых окон; есть команды **без исходной клавиши**. На проверенных рабочих
контекстах доступно более 600 команд, но число зависит от обнаруженных окон и
контекстных меню. Если нужную кнопку трудно найти, **`Choose command in app...`**
скрывает редактор: `Ctrl` + клик позволяет перейти к нужной вкладке/меню, обычный
клик выбирает команду для назначения, `Esc` заканчивает выбор. Кнопки конкретной
строки таблицы намеренно не привязываются к старой строке после смены выбора.

Клавиша выполняется только там, где команда применима: Pages, Takeoffs, viewport,
roof/overlay или соответствующий диалог. В модальном окне не запускаются скрытые
команды главного окна. Ввод текста и жесты мышью (`Ctrl/Shift/Alt` + click/drag)
сохраняют обычную работу. Назначение на поле ввода переводит в него фокус,
на список — открывает выбор; нужное значение вводится отдельно. Это не макрос
произвольного ввода и не настройка системного файлового диалога. Отключённый модуль или
read-only проект остаётся ограничением и при назначенной клавише.

При сообщении о нечитаемом файле назначений открой **`Recover settings...`**:
`Retry reading`, `Restore / import...` либо подтверждённый `Reset to original keys`.
Старые байты и копии восстановления сохраняются. Обычный Save не перезаписывает
защищённый повреждённый файл.

## Исходные назначения

Ниже — defaults, а не обязательные клавиши после изменения профиля.
Актуальные назначения смотри в редакторе и помощи ++f1++.

=== "Global / tools"

    | Клавиша | Действие |
    | --- | --- |
    | ++f1++ | Показать/закрыть шпаргалку клавиш |
    | ++esc++ | Закрыть помощь / отменить активное действие |
    | ++ctrl+o++ / ++ctrl+shift+o++ | Общий выбор проекта / выбор с недавними проектами |
    | ++ctrl+s++ | Save |
    | ++ctrl+shift+s++ | Save As с сохранением формата проекта |
    | ++ctrl+m++ / ++ctrl+shift+m++ | Merge / Split сегментов |
    | ++ctrl+shift+p++ | Command Palette |
    | ++space++ | Старт/стоп `Record` |
    | ++t++ | Новый takeoff item |
    | ++b++ ++k++ | Add Bookmark (последовательно, до 0.9 с) |
    | ++f4++ / ++f5++ | Set Scale на выбранных листах / Open Name-Scale |
    | ++minus++ | Свернуть деревья Pages и Takeoffs |
    | ++v++ / ++e++ / ++s++ / ++r++ | Pan / Select / Scale / Ruler |
    | ++h++ / ++d++ / ++n++ | Highlighter / Draw Line (Extra Joists) / Note |
    | ++p++ / ++l++ / ++a++ / ++j++ | Count / Line / Area / Joist Area |
    | ++b++ / ++o++ / ++x++ | Beam / Openings / Area Cut |

=== "Viewport"

    | Клавиша | Действие |
    | --- | --- |
    | ++c++ | Завершить текущее рисование |
    | ++enter++ / ++tab++ | Layer Trace: следующий этап / вариант; Tab также переключает edge-snap |
    | ++f++ | Fit page |
    | ++f2++ | Rename takeoff выбранного объекта |
    | ++f3++ / ++ctrl+f3++ | Snap / PDF Snap |
    | ++f8++ / ++f9++ | Ortho / Box mode |
    | ++shift++ | Временно форсить Ortho (при рисовании) |
    | ++ctrl+plus++ / ++ctrl+minus++ | Зум +/− |
    | ++ctrl+z++ / ++backspace++ | Undo действия / последней точки |
    | ++ctrl+a++ / ++ctrl+c++ / ++ctrl+v++ | Выбрать всё / копировать / Paste Measurements |
    | ++delete++ | Удалить выбранное |
    | ++ctrl++ / ++ctrl+shift++ / ++alt++ | Добавить-toggle / убрать из выбора / вершины |

=== "Trees / guides"

    | Клавиша | Действие |
    | --- | --- |
    | ++ctrl+c++ / ++ctrl+x++ / ++ctrl+v++ / ++ctrl+d++ | Copy / Cut / Paste / Duplicate |
    | ++ctrl+up++ / ++ctrl+down++ | Двигать узел вверх/вниз |
    | ++ctrl+enter++ | (Takeoffs) выбрать measurements секции на canvas |
    | ++f2++ / ++delete++ | Rename / Delete |
    | ++ctrl+z++ | (Pages/Takeoffs) вернуть последнее удаление в этом дереве |
    | ++esc++ | (Pages) очистить выбор; в рисовании — отменить действие |
    | ++enter++ | Открыть выбранный bookmark / AI-запись |
    | ++tab++ | Layer Trace: цикл edge-snap / кандидата (после включения) |
    | 3D Roof guide: ++r++ ++h++ ++v++ ++e++ ++k++ ++p++ | Ridge / Hip / Valley / Eave / Rake / Pitch |

    В режиме Roof guide ++backspace++ / ++ctrl+z++ возвращают последнюю точку,
    ++esc++ отменяет текущую линию или выключает режим, если линия не начата.
    `T` в рабочем окне создаёт takeoff; для включения Layer Trace используй
    соответствующую кнопку. `F5` — Name / Scale, а не обновление AI Inbox.

=== "Sheet Overlay"

    Эти клавиши меняют активное наложение листа, а не геометрию takeoff.

    | Клавиша | Действие |
    | --- | --- |
    | ++ctrl+alt+left++ / ++right++ / ++up++ / ++down++ | Сдвиг наложения (Ctrl+Alt удерживаются для каждой стрелки) |
    | ++ctrl+alt+plus++ / ++ctrl+alt+minus++ | Масштаб наложения |
    | `Ctrl+Alt+[` / `Ctrl+Alt+]` | Поворот наложения |
    | ++ctrl+alt+0++ | Сброс преобразования |
    | Добавить ++shift++ к сочетанию | Точный шаг сдвига/масштаба/поворота |
